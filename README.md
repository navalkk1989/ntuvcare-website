# NTUV Care – Website

AC Service, Repair & Copper Piping Work – booking website with Customer, Technician, Office and Admin panels.

| File | What it is |
|---|---|
| `index.html` | The complete website (videos and photos are inside this file) |
| `pincodes-india.json` | India pincode list used by the technician service-area feature |
| `NTUV-Care.apk` | Android app - downloaded by the "Download App" button in the header |
| `media/` | Optional 1080p background videos (sharper video on big screens) |
| `.nojekyll` | Tells GitHub Pages to serve the files exactly as they are |

Live site (after GitHub Pages is switched on): `https://<your-github-username>.github.io/ntuv-website/`

Data is saved in Google Sheet + Google Drive through the Apps Script web app (URL already set in `index.html`).
